### ⛓️ DataMint AI
**Winner — UCI Blockchain Mentorship Program Hackathon**

A decentralized marketplace for AI training data designed to improve **dataset ownership, provenance, transparency, and compensation**.

- Allows contributors to list datasets and AI developers to purchase or request training data
- Uses **IPFS** to store datasets off-chain while preserving verifiable content identifiers
- Links datasets to wallet identities to create a transparent provenance layer
- Uses smart contracts to automate payments between data contributors and developers
- Built around the problem that the people producing valuable AI training data often lack transparent ownership and compensation

**Tech:** Blockchain, Smart Contracts, IPFS, Web3, AI Data Infrastructure

Link: [DataMint AI](https://github.com/aanya2005/blockchain-ai-marketplace)
